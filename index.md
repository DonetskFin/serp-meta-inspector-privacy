Політика конфіденційності SERP Meta Inspector
Дата: 20 листопада 2026 року. Перевірена версія: 1.7.41.

Призначення
SERP Meta Inspector виконує SEO-аналіз вибраних користувачем сторінок, порівняння сторінок та моніторинг змін. Аналіз запускається користувачем; моніторинг може виконуватися за налаштованим ним розкладом.

Оброблювані дані
• Введені або вибрані URL-адреси, заголовки сторінок, пошуковий контекст, позиції результатів та час явного вибору/перевірки.
• HTTP-статуси, перенаправлення, canonical, hreflang, мова, SEO-метадані та зв'язки між обраними сторінками.
• За запитом користувача — HTML, DOM, тексти, структура та скріншоти сторінок для Content SEO, Page Compare та SEO Drift. Вміст залежить від вибраної сторінки і може містити дані, доступні в поточній браузерній сесії.
• Вибірки, налаштування, власні тексти користувача, звіти, історія та стан завдань.
• Під час налаштування проксі — сервер, порт, вибраний регіон та введені облікові дані проксі.
• При ручному тесті проксі — його вихідна IP-адреса, яка отримується від api.ipify.org і відображається користувачеві. Розширення не використовує GPS та не визначає фізичне розташування користувача.

Використання та зберігання
Ці дані використовуються для функцій SEO-аналізу, порівняння, моніторингу, збереження робочих списків та управління з'єднанням. Дані розширення зберігаються локально у профілі Chrome за допомогою chrome.storage та IndexedDB. Розширення не має обов'язкового хмарного облікового запису і не надсилає звіти на сервер розробника. Загальна історія відвідувань, усі натискання клавіш та поведінка на довільних сторінках не збираються для аналітики.

Мережеві звернення та одержувачі
Локальне зберігання не означає відсутності мережевих запитів. Для перевірок розширення звертається до вибраних сайтів та адрес, виявлених у їх SEO-зв'язках згідно з налаштуваннями перевірки, а для пошуку та оцінки кількості сторінок домену - до Google. Ці послуги отримують стандартні дані мережного запиту, зокрема запитуваний адресу і IP з'єднання.
При ручному тесті проксі запит api.ipify.org використовується для отримання вихідного IP. Якщо користувач включає свій проксі, з'єднання проходить через вибраного постачальника, а облікові дані передаються цьому проксі для авторизації. Налаштування проксі застосовується до всього звичайного профілю Chrome, доки воно увімкнено.
При відкритті сторінок у тимчасових вкладках Chrome може використовувати існуючу сесію сайту та його cookies у відповідному звичайному або приватному контексті. Розширення не копіює cookies між цими контекстами.

Експорт
Користувач може самостійно експортувати звіти, резервні копії та захоплені матеріали. Стандартна резервна копія JSON виключає збережені паролі проксі. HTML, тексти та зображення зберігають відомості вибраної сторінки: користувач повинен враховувати це перед передачею файлів іншим особам.

Обмеження використання
Розробник не продає дані та не використовує їх для реклами, не пов'язаних з функціями розширення цілей, визначення кредитоспроможності чи кредитування. Дані використовуються та передаються лише в обсязі, необхідному для описаних функцій. Використання даних відповідає Chrome Web Store User Data Policy, включаючи вимоги Limited Use.

Термін зберігання та видалення
Локальні звіти, записи контенту, знімки та історія зберігаються до видалення користувачем засобами відповідного розділу розширення або видалення даних розширення в Chrome. Експортовані користувачем файли зберігаються окремо та видаляються самим користувачем. Для видалення всіх локальних даних розширення можна видалити розширення з цього профілю Chrome. Тимчасові службові записи очищаються принаймні завершення операцій чи закінчення терміну дії.

Захист
Локальні дані захищаються засобами профілю Chrome та операційної системи. Збережені паролі проксі знаходяться на chrome.storage.local; додаткове шифрування на рівні програми у цій версії не реалізовано. Не використовуйте загальний незахищений профіль для зберігання конфіденційних даних.

Зміни
При зміні обробки даних політика та декларація у Chrome Web Store повинні оновлюватися до публікації відповідної версії.
